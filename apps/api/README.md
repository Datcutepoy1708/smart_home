# Smart Home API

NestJS modular-monolith backend for authentication, households, IoT devices,
MQTT ingestion, telemetry, automation, WebSocket updates, and FCM notifications.

From the repository root:

```text
npm install
npm run db:generate
npm run dev:api
```

Health endpoint: `GET http://localhost:3000/api/v1/health`

Development Swagger: `http://localhost:3000/docs`
